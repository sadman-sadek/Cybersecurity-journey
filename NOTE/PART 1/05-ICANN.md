# ICANN

## What is ICANN?

ICANN stands for:

**Internet Corporation for Assigned Names and Numbers**

ICANN is a global non-profit organization involved in coordinating important parts of the Internet's naming and addressing systems.

It helps maintain a globally coordinated and unique Internet namespace.

---

# What Does ICANN Do?

ICANN is mainly involved in the coordination of:

- Domain Name System (DNS) root
- Top-Level Domains (TLDs)
- Domain name policies and coordination
- IP address-related global coordination through the Internet number registry ecosystem

ICANN does not own the Internet and does not control individual websites.

---

# Why Is Coordination Necessary?

Imagine two unrelated organizations could independently create the same global domain name:

    example.com

This could create conflicts and make the Internet's naming system unreliable.

Global coordination helps ensure that domain names are unique within the global DNS namespace.

---

# Domain Name Structure

Consider:

    www.example.com

It can be viewed as:

    www      → Host / Subdomain
    example  → Second-level domain
    .com     → Top-Level Domain (TLD)

Examples of TLDs include:

    .com
    .org
    .net
    .edu
    .bd
    .uk

---

# TLD

TLD means:

**Top-Level Domain**

It is the highest-level part of a domain name.

Examples:

    example.com
             ↑
            TLD

    example.org
             ↑
            TLD

Country-code TLD examples:

    .bd
    .uk
    .jp

---

# Registry, Registrar, and Registrant

These terms are important for understanding domain registration.

## Registry

A registry operates the authoritative database/service for a particular TLD or domain namespace.

Example concept:

    .com
      ↓
    Registry
      ↓
    Domain records

---

## Registrar

A registrar provides domain registration services to customers.

Simplified:

    User
      ↓
    Registrar
      ↓
    Domain Registration

---

## Registrant

The registrant is the person or organization that registers a domain name.

Example:

    User → Registrar → example.com

The user/organization is the registrant.

---

# ICANN vs DNS

ICANN and DNS are not the same thing.

## DNS

DNS is the technical naming system used to resolve domain names.

Example:

    example.com
         ↓
        DNS
         ↓
    IP Address

## ICANN

ICANN is an organization involved in global coordination and policy processes related to the DNS and Internet identifiers.

Simplified:

    DNS = Technical naming system

    ICANN = Global coordination organization

---

# Simple Domain Registration Flow

A simplified model:

    ICANN / DNS Ecosystem
              ↓
            TLD
              ↓
           Registry
              ↓
          Registrar
              ↓
          Registrant
              ↓
         Domain Name

The real ecosystem contains additional organizations, policies, and technical components.

---

# ICANN and Cybersecurity

ICANN is not a firewall, antivirus, or security tool.

However, understanding the domain ecosystem is important in cybersecurity.

Attackers can abuse domain names for:

- Phishing
- Malicious websites
- Typosquatting
- Domain impersonation
- Command-and-control infrastructure

Example:

    Legitimate:
    example.com

    Possible typosquatting:
    examp1e.com

The domains may look similar to a human user but can point to completely different infrastructure.

---

# Important Distinction

ICANN does NOT:

- Own the Internet
- Control all Internet traffic
- Manage every website
- Act as a firewall
- Directly resolve every DNS query

Its role is primarily global coordination of important Internet naming and numbering resources.

---

# Key Takeaway

ICANN helps coordinate the global Internet naming and addressing ecosystem so that Internet identifiers remain unique and interoperable.

Remember:

    ICANN
      ↓
    Global Coordination
      ↓
    Internet Naming & Numbering Ecosystem

And:

    DNS → Resolves domain names

    Registry → Operates a TLD/domain registry

    Registrar → Provides domain registration services

    Registrant → Registers/holds a domain
