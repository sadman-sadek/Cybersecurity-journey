# 13. Cryptography

## 1. What is Cryptography?
Cryptography is the use of mathematical techniques to protect information from unauthorized access, modification, or misuse.

In simple words:
> **"Cryptography is a method of protecting data using mathematical techniques."**

It is widely used in cybersecurity to provide:
- Confidentiality
- Integrity
- Authentication
- Non-repudiation

---

## 2. Why is Cryptography Needed?
Sensitive information can travel through untrusted networks. Without proper protection, an attacker may capture or modify the data. Cryptography helps protect information during storage and communication.

### Basic Mechanism
```text
Plaintext
    ↓
Encryption
    ↓
Protected Data
    ↓
Network
    ↓
Decryption
    ↓
Plaintext
```

---

## 3. Basic Cryptography Terms

- **Plaintext:** The original readable data.
  * *Example:* `Hello Tasin`
- **Ciphertext:** The protected or encrypted form of plaintext.
  * *Example:* `x7F@9#kL...`
- **Encryption:** Converts plaintext into ciphertext.
  * `Plaintext → Encryption → Ciphertext`
- **Decryption:** Converts ciphertext back into plaintext.
  * `Ciphertext → Decryption → Plaintext`
- **Key:** A cryptographic value used by an algorithm during encryption, decryption, or other cryptographic operations.

---

## 4. How Encryption Works
The basic process is:

```text
Plaintext
    ↓
Encryption + Key
    ↓
Ciphertext
    ↓
Decryption + Key
    ↓
Plaintext
```
Encryption makes the original data difficult for unauthorized people to understand.

---

## 5. Symmetric Encryption
Symmetric Encryption uses the same secret key for encryption and decryption.

```text
        Same Secret Key
        ↙           ↘
   Encryption     Decryption
       ↓               ↓
  Plaintext → Ciphertext → Plaintext
```

### Advantages
- Fast
- Efficient for large amounts of data

### Main Challenge
The secret key must be shared securely. If an attacker obtains the key, the attacker may be able to decrypt the protected data.

---

## 6. Asymmetric Cryptography
Asymmetric Cryptography uses two related keys:
- **Public Key:** Can be shared publicly.
- **Private Key:** Must remain strictly secret.

Asymmetric cryptography is commonly used for secure communication, authentication, and digital signatures.

---

## 7. Hashing
Hashing converts input data into a fixed-size hash value using a hash function. Hashing is generally designed as a one-way operation.

```text
Input
  ↓
Hash Function
  ↓
Hash Value
```

### Common Uses
- Password storage
- File integrity checking
- Data verification
- Digital signatures

---

## 8. Encryption vs Hashing

| Encryption | Hashing |
| :--- | :--- |
| Protects data | Generates a hash value |
| Can normally be decrypted with the appropriate key | Not normally reversed through decryption |
| Uses cryptographic keys | Uses a hash function |
| Commonly used for confidentiality | Commonly used for integrity and verification |

> 💡 **Easy Way to Remember:**
> *   *"Encryption → Protect and recover data"*
> *   *"Hashing → Verify data"*

---

## 9. Digital Signature
A Digital Signature is a cryptographic mechanism used to verify the authenticity and integrity of a message or document.

It can help answer:
- Who signed the data?
- Has the data been changed?

### Basic Concept
```text
Message
   ↓
Hash
   ↓
Digital Signature
   ↓
Receiver
   ↓
Verification
```
Digital signatures commonly use asymmetric cryptography.

---

## 10. Security Goals of Cryptography
- **Confidentiality:** Protect information from unauthorized access.
- **Integrity:** Help detect whether data has been modified.
- **Authentication:** Help verify the identity of an entity or the origin of information.
- **Non-Repudiation:** In appropriate digital-signature systems, provide evidence that can help prevent a signer from credibly denying a signature.

---

## 11. Real-World Uses of Cryptography
Cryptography is widely used in:
- HTTPS
- Online banking
- Secure messaging
- VPNs
- Password protection
- Digital signatures
- Secure file transfer

---

## 12. Important Things to Remember
- **Plaintext** → Original readable data
- **Ciphertext** → Encrypted data
- **Encryption** → Plaintext to ciphertext
- **Decryption** → Ciphertext to plaintext
- **Symmetric Cryptography** → Same secret key
- **Asymmetric Cryptography** → Public key + private key
- **Hashing** → One-way hash generation
- **Digital Signature** → Helps verify authenticity and integrity
