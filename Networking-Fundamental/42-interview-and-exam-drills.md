# 42 — Interview and Exam Drills

Answer aloud.

## Fundamentals

1. What happens after you type a URL?
2. What is the difference between MAC and IP?
3. What is a subnet?
4. Why does a host need a default gateway?
5. What does a switch learn?
6. What does a router decide?
7. Why does ARP exist?
8. What is DNS caching?

## TCP

9. Explain the TCP handshake.
10. Why do sequence numbers exist?
11. What is a TCP reset?
12. What is TIME_WAIT?
13. How would you recognize retransmission?

## Security

14. Why is NAT not the same as a firewall?
15. What is segmentation?
16. How can ARP spoofing work?
17. What evidence could reveal port scanning?
18. Why might encrypted traffic still be detectable as suspicious?

## Troubleshooting

19. Ping works but HTTPS fails. What do you test?
20. DNS works but TCP fails. What next?
21. Local subnet works but Internet fails. What next?
22. One host cannot communicate with peers. What might be wrong?

## Expert challenge

Explain this path:

```text
Laptop
→ Wi-Fi AP
→ switch
→ firewall
→ NAT
→ ISP
→ Internet router
→ CDN/load balancer
→ web server
```

Explain what happens to:

- MAC addresses
- IP addresses
- ports
- TTL
- encryption
- routing decisions
- logs

at every meaningful boundary.
