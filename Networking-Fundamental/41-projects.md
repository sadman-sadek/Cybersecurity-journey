# 41 — Portfolio Projects

## Project 1 — Personal Network Observatory

Build a dashboard/report that inventories:

- interfaces
- routes
- DNS
- listening services
- active connections

## Project 2 — Packet Analysis Notebook

Collect 20 captures and explain each.

## Project 3 — Subnet Planner

Write a tool that accepts:

```text
network
required host counts
```

and produces a subnet plan.

```text
domain
```

- A

- MX
- NS
- TXT
- CNAME
- TTLs

## Project 5 — Network Baseline

Measure normal:

- DNS volume
- outbound connections
- destinations
- ports
- bandwidth

Then detect deviations.

## Project 6 — Secure Enterprise Design

Design a network for:

- 500 users
- public web service
- internal APIs
- database
- remote employees
- guest Wi-Fi
- security monitoring

Deliver:

- topology
- IP plan
- VLAN plan
- firewall matrix
- routing design
- logging design
- threat model
