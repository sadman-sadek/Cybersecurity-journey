# 12 — IPv6

IPv6 uses 128-bit addresses.

Example:

```text
2001:db8:1234:5678::10
```

## Why learn it?

Cybersecurity cannot assume IPv4 forever.

You need to recognize:

- global unicast
- link-local
- multicast
- loopback
- unique local addresses
- address compression
- prefix notation

## Compression

```text
2001:0db8:0000:0000:0000:0000:0000:0010
```

can be compressed to:

```text
2001:db8::10
```

## Important differences from IPv4

- 128-bit addresses
- no broadcast
- multicast is heavily used
- Neighbor Discovery replaces ARP
- extension headers can complicate inspection
- IPv6 can exist silently on networks even when administrators think only IPv4 matters

## Security checklist

Always ask:

```text
Is IPv6 enabled?
Are firewall rules covering IPv6?
Are logs collecting IPv6?
Are monitoring tools inspecting IPv6?
Are security policies accidentally IPv4-only?
```
