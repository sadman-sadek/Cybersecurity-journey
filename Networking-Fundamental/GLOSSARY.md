# Networking Glossary

**ACL** — Access Control List.

**ARP** — Address Resolution Protocol for mapping IPv4 addresses to Layer-2 addresses on local networks.

**BGP** — Border Gateway Protocol; a major inter-domain routing protocol.

**Broadcast domain** — A Layer-2 scope in which broadcasts are propagated.

**CIDR** — Classless Inter-Domain Routing; prefix-based addressing such as `/24`.

**DHCP** — Dynamic Host Configuration Protocol.

**DNS** — Domain Name System.

**EtherType** — Ethernet field indicating payload protocol/type.

**Firewall** — A policy enforcement device/system for network traffic.

**ICMP** — Internet Control Message Protocol.

**IP** — Internet Protocol.

**MAC** — Media Access Control address used for Layer-2 delivery.

**MTU** — Maximum Transmission Unit.

**NAT** — Network Address Translation.

**NIC** — Network Interface Controller/card.

**OSPF** — Open Shortest Path First; an interior routing protocol.

**Packet capture** — Recorded network traffic for analysis.

**Port** — Transport-layer endpoint identifier.

**Prefix length** — Number of network bits in an IP prefix.

**Router** — Device that forwards packets between networks.

**Socket** — Software abstraction representing a communication endpoint.

**Subnet** — An IP prefix representing a network range.

**TCP** — Transmission Control Protocol.

**TTL** — IPv4 Time To Live; limits packet lifetime across routers.

**UDP** — User Datagram Protocol.

**VLAN** — Virtual LAN; logical Layer-2 segmentation.

**VPN** — Virtual Private Network; protected/tunneled connectivity.

**Wireshark** — Graphical packet-analysis tool.

**Zero Trust** — Security approach emphasizing explicit verification and least-privilege access rather than implicit network trust.
