# LINUX COMMANDS ✴️

- `pwd` -It stands for Print work directory
         It will show where are we.
-  `ls` -list
        the list of files/folder that directory
- `ls -a` -showes the hidden files of that directory.
- `cd ..` -cd stand for change directory <br> -backwords one step.
- `cd /'something'` -fetch to the existing folder.
- `whoami` -shows user name.
- `cat` -stands for concatenate <br>
        shows whatever inside the file in text order.
- `cp` -stadns for copy.
- `sudo ` -Stands for super-user  do or substitute user do.
- `su`  -stands for switch user.
- `sudo su ` -to enter root shell.
- `rm ` -stands for remove.
- `bash` -stands for bourne again shell.
- `ps` -stands for process status
