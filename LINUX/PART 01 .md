# LINUX COMMANDS ✴️


- ### 📂 Essential Linux Commands Reference

* **`mkdir`** - *Stands for:* **Make Directory**
  * **Usage:** Used to create one or multiple new folders (directories) at a specified location.
  * **Example:** `mkdir new_folder`

* **`rmdir`** - *Stands for:* **Remove Directory**
  * **Usage:** Used to safely delete folders that are completely empty without losing any data.
  * **Example:** `rmdir empty_folder`

* **`touch`** - *Stands for:* **Touch (Modify file timestamps)**
  * **Usage:** Primarily used to instantly create new empty files or update the access/modification time of existing files.
  * **Example:** `touch new_file.txt`
