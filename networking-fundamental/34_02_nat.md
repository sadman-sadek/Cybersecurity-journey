# NAT

Network Address Translation changes address information as traffic crosses a translation device.

A common home setup:

```text
Private LAN
192.168.1.0/24
      |
    Router
      |
Public ISP address
      |
   Internet
```

Many private hosts can share a public IPv4 address using port translation, commonly called PAT/NAPT.

## Important distinction

NAT is **not** the same thing as a firewall.

NAT changes/maintains address mappings.

A firewall enforces traffic policy.

A consumer router often performs both, which causes the concepts to be confused.
