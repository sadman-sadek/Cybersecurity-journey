# ICMP

ICMP provides control, diagnostics and error messaging for IP networks.

Common examples:

- Echo Request
- Echo Reply
- Destination Unreachable
- Time Exceeded

`ping` commonly uses ICMP Echo messages for IPv4.

`traceroute`/`tracert` relies on TTL/hop-limit behavior and ICMP responses in common implementations.

## Important misconception

ICMP is not simply "the ping protocol".

Ping is an application/tool that commonly uses ICMP Echo.

ICMP is a broader protocol family.

## IPv6

ICMPv6 is essential to IPv6 operation, including Neighbor Discovery.
