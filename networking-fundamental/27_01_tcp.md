# TCP

TCP provides reliable, ordered, connection-oriented byte-stream transport.

Important concepts:

- source/destination ports
- sequence numbers
- acknowledgments
- retransmission
- flow control
- congestion control
- connection establishment/termination

## Three-way handshake

Simplified:

```text
Client → SYN → Server
Client ← SYN-ACK ← Server
Client → ACK → Server
```

This establishes TCP state.

## Why sequence numbers?

They let TCP track bytes and detect missing/out-of-order data.

## Reliability is not free

TCP can introduce:

- retransmissions
- additional control traffic
- latency under loss
- head-of-line blocking at the byte-stream level

Use the mental model, not the slogan "TCP is reliable".
