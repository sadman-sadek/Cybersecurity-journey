# DNS

DNS translates names into information such as IP addresses.

Example:

```text
www.example.com
        ↓
DNS resolution
        ↓
IP address
```

## Typical resolution story

1. Application asks the OS resolver.
2. Resolver checks local caches/hosts data.
3. A DNS query is sent to a configured resolver if needed.
4. The resolver may query authoritative infrastructure.
5. Answer returns.
6. Result is cached according to TTL.

## Important record types

- A → IPv4 address
- AAAA → IPv6 address
- CNAME → canonical name alias
- MX → mail exchange
- NS → authoritative name servers
- TXT → arbitrary text data used for various purposes

## Troubleshooting

If IP access works but a hostname does not:

- check DNS configuration
- query the resolver directly
- inspect the response
- check DNS reachability
- check the record itself
