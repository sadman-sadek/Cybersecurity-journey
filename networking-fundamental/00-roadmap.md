# 00 — Roadmap

## Level 1 — Vocabulary

Learn:

- network
- node
- host
- client
- server
- endpoint
- LAN / WAN
- packet / frame / segment
- protocol
- address
- port
- interface
- bandwidth / throughput / latency

**Checkpoint:** Explain a home network without using jargon you cannot define.

## Level 2 — Communication model

Learn:

- encapsulation
- decapsulation
- OSI
- TCP/IP
- headers
- payload
- addressing at different layers

**Checkpoint:** Explain what happens when one computer sends data to another.

## Level 3 — Local networking

Learn:

- Ethernet
- MAC addresses
- switches
- CAM/MAC table
- broadcast
- unicast
- multicast
- ARP
- VLAN concept

**Checkpoint:** Explain how a host finds the destination MAC on a LAN.

## Level 4 — IP networking

Learn:

- IPv4
- IPv6
- subnet masks
- CIDR
- default gateway
- private/public addresses
- subnetting
- routing

**Checkpoint:** Given an IP/mask, calculate network, broadcast, usable range and host count.

## Level 5 — Transport + applications

Learn:

- TCP
- UDP
- ports
- sockets
- DNS
- DHCP
- HTTP/HTTPS
- SSH
- TLS
- ICMP

**Checkpoint:** Explain a browser connection from hostname to response.

## Level 6 — Operations

Learn:

- packet capture
- troubleshooting
- DNS failures
- routing failures
- MTU problems
- duplicate IPs
- port/service failures
- Wi-Fi failures

**Checkpoint:** Diagnose a broken connection using evidence rather than guessing.

## Level 7 — CCNA bridge

Then learn:

- VLANs
- trunks
- STP
- inter-VLAN routing
- static routes
- dynamic routing concepts
- ACLs
- NAT
- DHCP configuration
- IPv6
- network automation basics

The foundation makes these topics much easier.
