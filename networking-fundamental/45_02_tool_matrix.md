# Tool → Question Matrix

| Tool | Question |
|---|---|
| ping | Can I exchange ICMP Echo messages? |
| traceroute/tracert | Where does path behavior change? |
| ipconfig/ip | What IP configuration do I have? |
| arp/ip neigh | What local neighbor mappings exist? |
| nslookup/dig | What does DNS return? |
| ss/netstat | What sockets/connections/listeners exist? |
| curl | Does an application protocol request work? |
| Wireshark | What actually crossed the interface? |

Use multiple tools to test one hypothesis.
