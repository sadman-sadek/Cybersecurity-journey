# Networking Foundations — Beginner → CCNA-Ready → Cybersecurity Strong

> **Mission:** Build networking intuition so strong that CCNA material stops feeling like memorization and starts feeling like a logical system.

This repository is a **foundation course**, not a certification cram sheet. It is designed for a beginner who wants to understand what actually happens when devices communicate.

## How to use this repository

Do **not** read it like a textbook.

For every concept:

1. **Predict** — what do you think will happen?
2. **Visualize** — draw the topology.
3. **Explain** — say it in your own words.
4. **Build** — reproduce it in a lab.
5. **Capture** — inspect packets when possible.
6. **Break** — deliberately make something fail.
7. **Fix** — troubleshoot from evidence.
8. **Teach** — explain it without notes.

### The golden question

Whenever two machines communicate, ask:

> **Who is talking to whom, using what protocol, over what path, with what addressing, and how does each device know what to do next?**

If you can answer that question at every layer, networking becomes much easier.

## Roadmap

| Phase | Area | Goal |
|---|---|---|
| 0 | Start Here | Learn how to learn networking |
| 1 | Core concepts | LAN, WAN, hosts, clients, servers, packets |
| 2 | Models | OSI + TCP/IP |
| 3 | Ethernet | Frames, MAC, switches, VLAN concepts |
| 4 | IP | IPv4, IPv6, addresses, masks |
| 5 | Subnetting | Calculate networks, hosts, ranges |
| 6 | Network behavior | ARP, ICMP, routing |
| 7 | Transport | TCP, UDP, ports |
| 8 | Applications | DNS, DHCP, HTTP(S), SSH, TLS, etc. |

| 12 | Troubleshooting | Layered troubleshooting |
| 13 | Labs | Build and break networks |
| 14 | CCNA bridge | Vocabulary and concepts before CCNA |

## Recommended lab tools

- Packet Tracer
- Wireshark
- A Linux VM
- Windows PowerShell / Command Prompt
- Basic network utilities: `ping`, `traceroute`/`tracert`, `ip`, `ipconfig`, `arp`, `nslookup`, `dig`, `ss`/`netstat`, `curl`

## Completion standard

You are **not done** because you can define a term.

You are done when you can:

- draw it,
- predict it,
- observe it,
- configure it,
- troubleshoot it,
- and explain why it behaves that way.

## Next step

After completing this foundation, begin your preferred **NetworkChuck CCNA** material. During CCNA, return here whenever a concept feels like a memorization exercise. The purpose of this repository is to give you the underlying mental model.
