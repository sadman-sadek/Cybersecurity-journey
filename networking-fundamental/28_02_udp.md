# UDP

UDP is a connectionless datagram transport.

It provides:

- source/destination ports
- length
- checksum

It does not itself provide TCP-style:

- connection establishment
- ordered delivery
- retransmission
- congestion control

Applications can implement their own mechanisms.

UDP is useful when low overhead, application-controlled behavior, or timely delivery is valuable.

Examples of applications/protocols that can use UDP include DNS and modern HTTP/3 transport via QUIC.
