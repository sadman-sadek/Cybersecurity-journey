# Lab — Map Your Home/Practice Network

Do this only on networks and devices you are authorized to inspect.

## Goal

Build a mental map.

Document:

```text
Internet
   |
ISP device
   |
Router
   |
Switch/AP
 |  |  |
PC Phone IoT
```

Record:

- IP ranges
- gateway
- DNS
- wireless SSIDs
- connected devices you own/control
- wired/wireless separation
- DHCP behavior

## Questions

1. Which device is the default gateway?
2. Which devices share a subnet?
3. What is the broadcast domain?
4. Where does NAT happen?
5. Where would a firewall policy apply?
