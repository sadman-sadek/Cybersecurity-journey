# Wi-Fi Foundations

Wi-Fi uses radio communication instead of a physical cable between client and access point.

## Important concepts

- SSID
- BSSID
- access point
- station/client
- channel
- channel width
- interference
- authentication
- encryption
- roaming

## Performance factors

Wireless performance depends on:

- signal quality
- interference
- distance
- obstacles
- channel utilization
- client capabilities
- AP capabilities
- protocol overhead

## Security

Modern Wi-Fi security commonly relies on WPA2/WPA3 families and strong authentication/configuration.

Do not confuse:

- SSID = network name
- BSSID = identifier associated with an AP radio/basic service set
