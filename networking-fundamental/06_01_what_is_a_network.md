# What Is a Network?

A network is a system that allows nodes to exchange information according to agreed rules.

## Core objects

- **Host:** an endpoint participating in communication.
- **Node:** a broader term for a connected device.
- **Interface:** a connection point to a network.
- **Link:** a communication path between interfaces.
- **Protocol:** rules governing communication.
- **Address:** an identifier used to locate or identify something at a particular layer.

## Why networks exist

Networks allow:

- resource sharing
- communication
- distributed applications
- remote access
- centralized services
- automation
- cloud computing

## Network vs Internet

A network can be private and local.

The **Internet** is a global interconnection of many independent networks using common protocols, especially IP.

## First mental model

Think in three questions:

1. **Identity:** Who am I?
2. **Destination:** Where am I sending?
3. **Path:** How do I get there?

IP addressing and routing answer much of #2 and #3. Link-layer addressing handles local delivery. Applications define what the data means.
