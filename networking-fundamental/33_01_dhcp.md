# DHCP

DHCP dynamically provides network configuration.

Common information includes:

- IP address
- subnet mask/prefix
- default gateway
- DNS servers
- lease information

## DORA

A common IPv4 DHCP exchange:

```text
Discover
Offer
Request
ACK
```

## Why broadcast?

A client may begin without an IPv4 configuration, so it uses broadcast-based discovery on the local network.

## Relay

Routers normally separate broadcast domains. DHCP relay functionality allows a DHCP request to be forwarded toward a DHCP server on another network.
