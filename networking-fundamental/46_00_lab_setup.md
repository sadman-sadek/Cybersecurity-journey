# Lab Setup

Recommended progression:

## Lab 1 — Your own machine

Inspect:

- IP address
- subnet
- gateway
- DNS
- routes
- ARP/NDP cache
- listening ports

## Lab 2 — Packet Tracer

Build:

```text
PC1 ─ Switch ─ PC2
```

Configure addresses manually and test connectivity.

## Lab 3 — Router

```text
PC1 ─ Switch ─ Router ─ Switch ─ PC2
```

Use two IP networks.

## Lab 4 — DNS/DHCP

Create a small network and observe address assignment and name resolution.

## Lab 5 — Wireshark

Capture:

- ARP
- ICMP
- DNS
- TCP handshake
- HTTPS metadata

## Lab rule

For every lab, create a `LAB_NOTES.md` containing:

- topology
- addressing table
- goal
- commands
- expected result
- actual result
- failures
- fix
- lessons learned
