# ARP — IPv4 Local Neighbor Resolution

ARP maps an IPv4 address to a Layer-2 MAC address on a local network.

Suppose:

```text
PC A: 192.168.1.10
PC B: 192.168.1.20
```

PC A knows B's IP but not B's MAC.

It broadcasts an ARP request roughly asking:

> Who has 192.168.1.20?

B replies with its MAC.

A stores the result in its ARP cache.

## If B is remote

Suppose B is `10.0.0.20`.

A does **not** ARP for B's remote MAC.

A ARPs for the MAC of its **default gateway**.

This distinction is foundational.

## Security

ARP has historically lacked strong authentication. Attackers on the same Layer-2 network can abuse ARP behavior for interception or disruption.

Learn the mechanism before learning the attack.
