# Network Security Foundations

Networking and security are inseparable.

## Core security goals

- confidentiality
- integrity
- availability
- authentication
- authorization
- accountability

## Segmentation

Separate systems based on trust and function.

Examples:

```text
Users VLAN
Servers VLAN
Guest VLAN
Management VLAN
IoT VLAN
```

Segmentation reduces unnecessary communication paths and limits blast radius.

## Defense layers

Think in layers:

1. physical
2. link
3. network
4. transport
5. application
6. identity
7. monitoring/logging

No single control is perfect.
