# LAN, WAN and Network Devices

## LAN

A Local Area Network connects devices over a limited area such as a home, office, lab or campus.

## WAN

A Wide Area Network connects networks over larger geographic areas.

The important distinction is not simply distance. It is the scope and administrative/network technology context.

## Common devices

### Switch

Primarily forwards Ethernet frames inside a LAN using MAC addresses.

### Router

Forwards packets between IP networks using routing information.

### Access Point

Provides wireless clients access to a network.

### Firewall

Enforces traffic-control/security policy.

### Modem / ONT

Terminology depends on access technology. These devices interface with ISP access infrastructure.

### Server

Provides a service.

### Client

Consumes a service.

## Don't memorize device names as boxes

Ask:

> What information does this device inspect, and what decision does it make?

That question scales into advanced networking.
