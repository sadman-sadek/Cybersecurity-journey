# Lab — Break It, Then Fix It

Create a small authorized lab.

Break one variable at a time:

- wrong IP
- wrong subnet mask
- wrong gateway
- wrong DNS
- wrong route
- blocked port
- stopped service

For each failure:

1. predict symptom
2. test
3. collect evidence
4. isolate layer
5. fix
6. retest
7. explain root cause

Do not fix by changing five things at once.
