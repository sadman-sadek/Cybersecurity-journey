# What You Should Know Before CCNA

Before going deeper into CCNA, you should be comfortable with:

## Must-know

- OSI/TCP-IP
- Ethernet
- MAC addresses
- switching
- broadcast domains
- IPv4
- subnet masks
- CIDR
- subnetting
- default gateway
- ARP
- ICMP
- routing
- longest prefix match
- TCP/UDP
- ports
- DNS
- DHCP
- NAT
- basic IPv6
- troubleshooting methodology

## Then CCNA becomes the next layer

Expect to deepen:

- VLANs
- trunking
- STP
- EtherChannel
- inter-VLAN routing
- static routes
- OSPF
- ACLs
- NAT
- DHCP
- IPv6
- wireless
- network management
- automation

The foundation and CCNA are not competing resources. The foundation explains **why**; CCNA develops configuration and operational skill.
