# IPv6 Foundations

IPv6 uses 128-bit addresses.

Example:

```text
2001:db8:1234:1::10/64
```

## Why IPv6?

IPv4 address space is limited. IPv6 provides a vastly larger address space and introduces architectural improvements.

## Important concepts

- 128-bit addressing
- hexadecimal notation
- prefix lengths
- link-local addresses
- global unicast addresses
- multicast
- Neighbor Discovery
- SLAAC
- DHCPv6 concepts

## Link-local

IPv6 link-local addresses commonly begin with `fe80::/10`.

They are used for communication on the local link and are fundamental to IPv6 operation.

## Important contrast

IPv6 does not use ARP. It uses **Neighbor Discovery Protocol (NDP)** through ICMPv6.
