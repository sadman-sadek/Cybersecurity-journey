# Final Challenge — Design and Defend a Network

Design a small organization network.

Requirements:

- 3 user groups
- server segment
- guest network
- management network
- Internet connection
- DNS
- DHCP
- secure administrative access
- basic segmentation

## Deliverables

### 1. Diagram

Show:

- routers
- switches
- APs
- servers
- clients
- firewalls
- links

### 2. Address plan

For each subnet:

- network
- prefix
- gateway
- host range
- broadcast (IPv4)

### 3. Traffic matrix

Define who can communicate with whom.

### 4. Routing plan

Explain:

- connected routes
- static/dynamic routes
- default route

### 5. Security plan

Include:

- segmentation
- least privilege
- management isolation
- logging
- secure protocols

### 6. Failure plan

Explain what happens if:

- DNS fails
- DHCP fails
- gateway fails
- one link fails
- a server stops
- an unauthorized host appears

### 7. Verification

Write commands/tests that prove each part works.

If you can design, build, break, troubleshoot and explain this network, you are ready to get far more value from CCNA study.
