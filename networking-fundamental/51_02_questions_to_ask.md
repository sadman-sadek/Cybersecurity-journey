# Questions to Ask During CCNA

When a lesson introduces a feature, ask:

1. What problem does this solve?
2. What layer does it primarily operate at?
3. What state does the device maintain?
4. What packets/frames are exchanged?
5. What addresses are involved?
6. What happens if it fails?
7. How would I verify it?
8. How could an attacker abuse it?
9. What configuration changes it?
10. Can I reproduce it in a lab?

This transforms CCNA from command memorization into network engineering.
