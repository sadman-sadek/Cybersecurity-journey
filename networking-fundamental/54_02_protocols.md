# Protocol Cheat Sheet

| Protocol | Purpose | Typical transport/port |
|---|---|---|
| Ethernet | LAN framing | Layer 2 |
| ARP | IPv4 neighbor resolution | Ethernet |
| ICMP | IP control/diagnostics | IP |
| DNS | Name resolution | 53 UDP/TCP |
| DHCP | Dynamic IPv4 configuration | 67/68 UDP |
| HTTP | Web | 80 TCP |
| HTTPS | HTTP over TLS | 443 TCP |
| SSH | Secure remote access | 22 TCP |
| NTP | Time synchronization | 123 UDP |
| SNMP | Network management | 161 UDP |
| BGP | Inter-domain routing | 179 TCP |
| OSPF | Interior routing | IP protocol 89 |
