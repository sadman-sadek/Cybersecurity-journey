# Lab — The Complete Packet Story

## Objective

Explain a browser connection from zero.

Use a browser or `curl`.

Document:

1. DNS query
2. resolved IP
3. local subnet decision
4. ARP/NDP
5. TCP or QUIC setup
6. TLS
7. HTTP request
8. response
9. packet capture evidence

## Deliverable

Create a diagram with:

- source/destination IPs
- source/destination ports
- local source/destination MACs
- gateway
- protocol at each stage

If you can do this confidently, your networking foundation is becoming real.
