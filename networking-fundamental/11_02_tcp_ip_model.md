# TCP/IP Model

A practical TCP/IP model is often described as:

1. Link
2. Internet
3. Transport
4. Application

Mapping to OSI:

```text
OSI 7-5  → Application
OSI 4    → Transport
OSI 3    → Internet
OSI 2-1  → Link
```

## Why TCP/IP matters

The Internet is built around the TCP/IP protocol suite.

Use OSI when reasoning about layers. Use TCP/IP when thinking about the actual protocol family and Internet architecture.
