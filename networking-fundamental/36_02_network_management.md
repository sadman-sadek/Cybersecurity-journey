# Network Management

Networks must be monitored and managed.

Important concepts:

- configuration management
- telemetry
- logs
- metrics
- alerts
- SNMP
- SSH
- APIs
- automation

## Three categories

### Configuration

What the network is supposed to do.

### State

What it is doing right now.

### Telemetry

What it has been doing over time.

Good troubleshooting compares intended configuration with observed state.
