# Network Security

## Definition
Network Security is the practice of protecting network devices,
data, and communication from unauthorized access, attacks,
modification, and disruption.

## Main Goals
- Confidentiality – prevent unauthorized access to data.
- Integrity – prevent unauthorized modification of data.
- Availability – keep systems and services accessible to authorized users.

## Common Network Security Mechanisms
- Firewall (CONTRILL TRAFFIC)
- Authentication (WEATHER REAL USER ?)
- Encryption ( ENCRICPT DATA THUS IN CAN'T BE READ.)
- VPN (PROVIDE ENCRIPTED CONNECTION)
-  Secure Wi-Fi (WPA2/WPA3)
- IDS/IPS
- Network Monitoring (MONITOR SUSPIOUS SCTIVITY)

## Simple Example
Internet → Router/Firewall → Internal Network → Devices

## Cybersecurity Relevance
Network security helps protect systems and data from unauthorized
access and network-based attacks.

## Remember
Network Security = Protecting networks, devices, communication, and data.
